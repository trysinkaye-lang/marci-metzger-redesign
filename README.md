# Marci Metzger homepage redesign

A single-page homepage redesign created for the Luxury Presence Junior Web Builder assessment.

## Stack

- React 19
- TypeScript
- Vite
- GSAP / ScrollTrigger
- Custom CSS
- ESLint

## Design direction

The redesign keeps Marci Metzger, The Ridge Realty Group, Pahrump, Nevada, and the original homepage content and imagery at the center of the experience. The visual direction is restrained editorial real estate: strong local photography, warm neutral tones, readable typography, generous spacing, and purposeful motion.

Key interactions include a scroll-expanding hero, an accessible depth carousel for the original photo gallery, a buyer journey, and an editorial services sequence. Mobile layouts reduce motion and simplify navigation.
